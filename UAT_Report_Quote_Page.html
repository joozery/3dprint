ปัญหาที่พบ — Critical
ต้องแก้ก่อน Release
🔴 Critical · C-01
Upload ไฟล์ต้องการ Login แต่ UI ไม่ตรวจสอบก่อน
API /api/quote/upload ส่งกลับ HTTP 401 ถ้าผู้ใช้ยังไม่ได้ login แต่ปุ่ม "อัพโหลดไฟล์" ใน UI ไม่มีการตรวจสอบ session ก่อน ผู้ใช้ที่ยังไม่ได้ login จะเห็นแค่ alert error message แทนที่จะถูก redirect ไปหน้า login อย่างเหมาะสม ส่งผลให้ประสบการณ์ผู้ใช้แย่และ flow ขาดตอน
QuoteApp.tsx : line 94 api/quote/upload/route.ts : line 18 Impact: ผู้ใช้ใหม่ทุกคน
แนวทางแก้: เพิ่มการตรวจสอบ if (!session) { router.push('/login?callbackUrl=/quote'); return; } ใน handleFileUpload ก่อนส่ง request ไป server
🔴 Critical · C-02
การคำนวณราคา Client vs Server ไม่ตรงกัน
Client-side ใช้ material._id (MongoDB ObjectId) ค้นหาวัสดุใน patchQuote() เพื่อคำนวณราคา แต่ Server-side PATCH endpoint ใช้ Material.findOne({ systemId: material }) ทำให้ server หา material ไม่เจอ → ราคาที่แสดงใน UI กับที่บันทึกลง Database ต่างกัน ส่งผลต่อความถูกต้องของ quote ที่ส่งให้ admin
QuoteApp.tsx : line 154 api/quote/[id]/route.ts : line 47 Impact: ราคาใน DB ผิด
แนวทางแก้: แก้ server ให้ใช้ Material.findById(material) แทน findOne({ systemId }) หรือให้ client ส่ง materialId ที่ถูกต้องและ consistent กัน

🟡 Medium · M-01
Coupon FIRST25 และ Setup Fee แสดงใน UI แต่ไม่ได้หักจากยอดรวมจริง
Price Breakdown แสดง "FIRST25 ลด ฿25.00" และ "Setup Fee ฿150.00" ในรายการ แต่สูตรคำนวณยอดสุดท้าย finalPrice = totalPrice + vat + deliveryCost ไม่ได้รวม/หัก ค่าทั้งสองนี้ ผู้ใช้เข้าใจว่าได้รับส่วนลดแล้ว แต่ยอดชำระจริงไม่เปลี่ยนแปลง
QuoteApp.tsx : line 247 QuoteApp.tsx : line 665–669 Impact: ราคาแสดงผลผิดพลาด
🟡 Medium · M-02
ปุ่ม "Save to Cart" ไม่ได้บันทึกข้อมูลจริง
ฟังก์ชัน handleSaveToCart มีเพียง alert("บันทึกลงตะกร้าเรียบร้อยแล้ว!") ไม่มี logic การบันทึกจริง ผู้ใช้ที่กดปุ่มนี้จะเข้าใจผิดว่าข้อมูลถูกบันทึกแล้ว แต่จริงๆ ไม่มีการเปลี่ยนแปลงใดๆ
QuoteApp.tsx : line 219–221 Impact: Feature ใช้งานไม่ได้
🟡 Medium · M-03
"ขอใบเสนอราคา" ไม่ตรวจสอบว่า Login หรือยัง
handleGetQuotation() ใน QuoteApp.tsx ไม่มีการ check session ก่อน POST ไป /api/quote/request ทำให้ผู้ใช้ที่ไม่ได้ login สามารถ proceed ไปหน้า /quote/request ได้ แต่เมื่อกด submit จะไม่สามารถผูก userId กับ Quote ได้ (ต่างจาก SidebarSummary.tsx ที่ redirect login ก่อน)
QuoteApp.tsx : line 199 SidebarSummary.tsx : line 32 Impact: Quote ไม่ผูก User
🟡 Medium · M-04
ปุ่ม "Copy to All" ไม่มี onClick Handler
ปุ่ม "Copy to All" ใน Configuration Panel มีแค่ UI ไม่มี event handler ผูกอยู่ กดแล้วไม่มีอะไรเกิดขึ้น ควร implement ฟังก์ชันที่ copy config ของ activeQuote ไปยัง quote อื่นทุกชิ้นในรายการ

Architecture Overview
ไฟล์ หน้าที่
app/quote/page.tsx Page root — จัดการ state quotes[], localStorage, ส่ง onAdd/onUpdate/onRemove ไปให้ QuoteApp
components/quote/QuoteApp.tsx Main UI — 4 panel layout: File List | 3D Viewer | Config | Price Summary
components/quote/Viewer3D.tsx Three.js 3D model renderer (Shaded/Wireframe/Wall Thickness/Size modes)
api/quote/upload/route.ts POST — วิเคราะห์ไฟล์ + อัพโหลด R2 + สร้าง Quote ใน DB
api/quote/[id]/route.ts GET/PATCH/DELETE — ดึง/อัพเดท/ลบ Quote รายชิ้น
api/quote/pending/route.ts GET — โหลด draft quotes จาก localStorage IDs หรือ userId
api/quote/request/route.ts POST — กำหนด sharedQuoteNumber ให้ quotes batch
api/quote/confirm/route.ts POST — บันทึก billing/shipping + เปลี่ยน status เป็น "pending"
app/quote/request/page.tsx หน้ากรอก billing/shipping สำหรับขอใบเสนอราคา
